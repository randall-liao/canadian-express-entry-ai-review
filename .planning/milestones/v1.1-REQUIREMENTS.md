# Requirements: PR Review Agents — v1.1 Corpus Coverage & Completeness

**Defined:** 2026-06-09
**Milestone:** v1.1 (continues from shipped v1.0)
**Core Value:** Every answer is grounded in and cited from an authoritative source — which
now also means the corpus is *measurably complete*, not a partial HTML skeleton.

## v1.1 Requirements

### Coverage Audit

- [x] **COV-01**: A coverage auditor parses every captured raw HTML page, extracts the
  authoritative links it references (per source type), and diffs them against what the
  corpus actually captured — producing a per-source gap report.
- [x] **COV-02**: The auditor classifies each referenced link as captured, missing, or
  out-of-scope (with the reason), so gaps are actionable and false positives are excluded.
- [x] **COV-03**: `pr-tools coverage` (and `python -m tools.coverage`) emit the gap report
  as JSON and human-readable output.

### Expanded Crawl

- [x] **XCR-01**: The crawler can follow authoritative links *beyond* a single seed's path
  prefix, governed by explicit scope guards (host allowlist + path-pattern allowlist +
  per-source page caps) so it stays authoritative and bounded.
- [x] **XCR-02**: Legislation crawling captures the regulations made under IRPA that the
  Act/Regulations pages reference (not only IRPA + IRPR full text), within the scope guards.
- [x] **XCR-03**: Guidance crawling captures the referenced Express-Entry pages that
  currently fall in sibling sections (e.g. publications, ministerial-instruction rounds),
  within the scope guards.
- [x] **XCR-04**: The expanded crawl remains polite (robots.txt, crawl-delay) and
  incremental (no refetch of unchanged content), and records attribution like the base crawl.

### Content-Completeness Validation

- [x] **CMP-01**: A content-completeness validator flags pages whose captured markdown is a
  thin "skeleton" relative to the page's full content (extends the existing coverage-ratio
  check to all source types, including detection of JS-rendered content gaps).
- [x] **CMP-02**: The validator cross-checks a sample of pages with the crawl4ai (JS-rendered)
  extractor and flags any page where rendered content materially exceeds the captured markdown.
- [x] **CMP-03**: The completeness check fails CI (non-zero exit) when a substantive page or a
  referenced authoritative document is missing or skeletal, with a clear report of which.

### Integration

- [x] **INT-01**: Running the expanded crawl + chunk + index refreshes the corpus end-to-end,
  and all existing document agents, the checklist, and conformance still pass the grounding gate.
- [x] **INT-02**: The coverage auditor and completeness validator are wired into CI alongside
  the existing PII/secret and test gates.

## Out of Scope (v1.1)

| Feature | Reason |
|---------|--------|
| New document agents / trackers / calculators | Deferred to a later milestone; v1.1 is about corpus completeness, not new features |
| Crawling non-authoritative / third-party sites | Corpus stays limited to IRCC / Justice Laws / IRCC PDIs |
| Other immigration programs (PNP, sponsorship) | Still out of scope; coverage work stays within post-ITA Express Entry authoritative sources |
| Layer-3 document content inspection | Deferred milestone item |
| Full historical "previous versions" of legislation | Capture current consolidated text + related regulations; historical diffs are out of scope |
