## 3. Cross-Phase Integration & Data Flow Trace

Cross-phase wiring was verified end-to-end across the entire pipeline:

```
[Phase 72: Research]
  Gemini 3.6 Flash Agents (23 doc types)
  └── Writes crawler/eval/pipelines/<doc_type>/research/research.json
        │

  Gemini 3.6 Flash Generator Agents + ReportLab Vector Compiler + PyPDFium Rasterizer
  └── Produces 118 logical cases & 236 PDFs (118 vector, 118 scanned)
  └── Writes crawler/eval/pipelines/<doc_type>/ground_truth/ground_truth.json
        │
        ▼ (staged via crawler/synthetic/staging.py outside repo root)
[Phase 74: Blind Worker Review]
  Gemini 3.6 Flash Workers (236 sessions in isolated CWDs)
  └── Reads only blind PDF + allowed extracted text
  └── Emits 236 AnswerObject JSON review reports
        │
        ▼ (consumed by pipeline_judge.py)
[Phase 74: Privileged Judge & Genuine Optimizer]
  23 Batched Claude Opus 4.8 Judges (xhigh, long_context) + Gemini Optimizers
  └── Reads Worker outputs + Phase 72 research + Phase 73 ground truth
  └── Evaluates prompt/skill candidate patches (accepted if train delta > 0 & holdout non-regressing)
  └── Writes crawler/eval/phase74_evidence/ (manifest, 11 accepted patches, 23 rejected patches)
        │
        ▼ (validated by validate_committed_phase74_evidence)
[Phase 75: Release Assessment & Root Report]
  release_orchestrator.py + CopilotSdkRuntime (gpt-5.6-sol, xhigh, long_context, is_live: true)
  └── Evaluates aggregate evidence and binds SHA-256 self-hashes
  └── test_report.py renders root TEST_REPORT.md
  └── Writes crawler/eval/phase75_evidence/ (assessment.json, release_evidence.json, manifest.json)
        │
        ▼ (operates via Lead Review Coordinator in AGENTS.md)
[Root Natural-Language Operational Workflow]
  User Intent: "I want to review X" / "review my passport"
  └── AGENTS.md Lead Review Coordinator routing -> corpus-crawler --json subcommands
  └── Stage 1: Setup & Ingestion (vault init/profile/ita/import, checklist)
  └── Stage 2: Extraction & Field Confirmation (vault extract, doctor, fields, confirm)
  └── Stage 3: Grounded Audit & Screening (vault audit, screen-mec, noc-review, study-review)
  └── Stage 4: Remediation & Review Packet Export (vault remediate, review-packet)
```
