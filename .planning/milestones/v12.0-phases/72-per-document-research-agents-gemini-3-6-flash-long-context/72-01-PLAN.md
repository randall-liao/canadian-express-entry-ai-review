<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Online Web → LLM Agent | Untrusted web search results and forum posts fetched by Copilot CLI could contain prompt injection or false policy claims. |
| LLM Agent → Local Pipeline Directory | Malicious or malformed LLM JSON output could attempt directory traversal or overwrite sibling pipeline files. |
| Subprocess Execution → Host Environment | Subprocess calls to Copilot or Python CLIs must use validated executable paths and restricted working directories. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-72-01 | Tampering / Prompt Injection | Online web sources → Gemini Agent | mitigate | Grounding Gate verifies policy assertions against `corpus/index.db` via `corpus-crawler --json search`. Unverified claims are reclassified as `discovery` (D-04, D-06). |
| T-72-02 | Information Disclosure | Copilot Subprocess Working Directory | mitigate | Execute Copilot CLI in a per-document isolated directory under `crawler/eval/pipelines/<doc_type>/research/` (WR-02, D-01, D-03, D-09). |
| T-72-03 | Input Tampering / Malformed JSON | Raw LLM Output → Pipeline Storage | mitigate | Enforce strict Pydantic `ResearchReport` and `FailureMode` validation. Reject malformed JSON and fail closed without saving (D-05, D-10). |
| T-72-04 | Elevation of Privilege / Executable Substitution | `_discover_copilot_executable()` | mitigate | Validate executable exists and is executable before invoking; sanitize `COPILOT_PATH` environment variable (WR-01). |
| T-72-05 | Bypassing Gate / Stale Success Reuse | `research.json` File System State | mitigate | Unlink `research.json` on error before recording `research.error.json` to prevent stale success artifacts from surviving (D-10). |
| T-72-06 | Misrepresentation / Ungrounded Policy | FailureMode Authority Field | mitigate | Fail closed on unsupported policy claims, forcing `authority_classification = "discovery"` if local corpus verification returns zero hits (D-06). |
</threat_model>
