<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Concurrent Thread Execution → File System | Parallel thread workers must not collide or write to overlapping path directories. |
| Research Manifest → Downstream Phase Seam | Research JSON artifacts must remain inside `crawler/eval/pipelines/<doc_type>/research/` and not leak into blind worker prompts. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-72-04 | Cross-Pipeline Disclosure / Collision | Concurrent Thread Workers | mitigate | Enforce path assertion `path.resolve().is_relative_to(_PIPELINES_DIR / doc_type)` in every worker thread before writing (D-01, D-03, D-09). |
| T-72-05 | False Metadata Claims | `execution` Metadata Recorder | mitigate | Record truthful command, model (`gemini-3.6-flash`), exit status, and SHA256 provenance token. Reject fake model labels (CR-03, D-12, D-14). |
| T-72-06 | Stale Success Reuse | `_record_research_failure()` | mitigate | Explicitly unlink `research.json` on thread execution failure before writing `research.error.json` (D-10). |
</threat_model>
