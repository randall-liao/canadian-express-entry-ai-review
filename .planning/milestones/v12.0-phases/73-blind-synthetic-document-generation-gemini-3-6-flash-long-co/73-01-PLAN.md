<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| External LLM Output to Python | Agent JSON payload from Gemini 3.6 Flash crosses into Python execution; must be parsed and validated before rendering. |
| Pipeline Ground Truth to Worker | Worker agents must not access ground truth, research JSON, or revealing filenames. |
| Subprocess to Host | Copilot CLI subprocess execution must use validated binary and isolated directory paths. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-73-01 | Prompt Injection | Generator Agent Prompt | mitigate | Sanitize research input injected into agent prompt; strictly enforce JSON output format and Pydantic schema validation. |
| T-73-02 | Input Tampering | GenerationSpec Fields | mitigate | Validate all agent-authored fields against Pydantic GenerationSpec schema before passing to PDF renderer. |
| T-73-03 | Repudiation / Fake Provenance | Generation Provenance | mitigate | Distinguish live copilot-cli from test-double runners; compute SHA256 hashes of prompt, output, and token. |
| T-73-04 | Spoofing / Deterministic Output | Synthetic Generator | mitigate | Prohibit fallback deterministic templates in production agent failure path; fail closed on error. |
| T-73-05 | Information Disclosure | Filename / Path Side Channels | mitigate | Assign 32-hex cryptographically random IDs (secrets.token_hex(16)); strip document type/variant suffixes from filenames. |
| T-73-06 | Information Disclosure | PDF Metadata Leakage | mitigate | Overwrite /Title, /Author, /Subject, /Keywords, /Creator, /Producer metadata in ReportLab/PDFium; run automated leakage scanner. |
| T-73-07 | Elevation of Privilege | Worker Staging Directory | mitigate | stage_case_for_worker copies single opaque PDF into fresh tempfile.TemporaryDirectory() outside pipeline tree with no symlinks. |
| T-73-08 | Denial of Service | Stale Artifact Persistence | mitigate | On generation or validation failure, unlink stale ground truth artifacts and write generation_error.json. |
| T-73-09 | Tampering / PII Leakage | Synthetic Case Content | mitigate | Use strictly fictional fixture identities; prohibit real candidate-vault data. |
| T-73-SC | Tampering | Package Installs | mitigate | Pre-verified stack (pydantic, reportlab, pypdfium2, Pillow, pdfminer.six); no runtime untrusted installs. |
</threat_model>
