<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Privileged Pipeline -> Worker Staging | Single opaque PDF & allowed extracted text staged outside pipeline tree |
| Worker CLI Session -> Filesystem | Execution commands run in staging CWD with no repo cwd or custom instructions |
| Worker Output -> Grounding Gate | Raw AnswerObject text checked against local corpus grounding rules |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-74-01 | Elevation of Privilege | Worker Execution | mitigate | Workers run in fresh staging CWD with zero repo access, no custom instructions, and no tools per D-03. |
| T-74-02 | Information Disclosure | Case Staging | mitigate | Opaque 32-hex IDs, non-sequential filenames, and automated side-channel leakage scans on staged files per D-02. |
| T-74-03 | Tampering / Elevation | PDF Attachment | mitigate | `stage_case_for_worker` validates path containment (`is_relative_to`), rejects symlinks, and asserts clean destination. |
| T-74-04 | Information Disclosure | Evidence Bundle | mitigate | Worker prompts contain only public review bundles constructed from canonical skills and local corpus per D-06. |
| T-74-05 | Tampering | Prompt Response | mitigate | Strict JSONL event parsing, Pydantic 5-field AnswerObject validation, and local grounding gate `check_answer_grounding`. |
| T-74-SC | Tampering | Package Audit | mitigate | Pre-installed packages only; no external package installations. |
</threat_model>
