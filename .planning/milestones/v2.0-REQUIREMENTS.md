# Requirements: v2.0 Shareable Crawler

Scope: turn the existing IRCC-hardcoded `crawler/` pipeline into a generic,
config-driven, MIT-licensed tool that is safe to publish publicly and invocable
by any CLI agent, while keeping a built-in IRCC/canada.ca profile so it works
out-of-the-box. This milestone refactors and productizes existing code; it does
not change the crawl/QC/completeness behavior for the IRCC default profile.

## Milestone v2.0 Requirements

### Config-Driven Engine (GEN)

- [ ] **GEN-01**: A user can define a crawl target entirely through an external site-profile config (allowed domains, include/exclude URL patterns, chrome-stripping rules, source label) without editing Python source.
- [ ] **GEN-02**: The crawler loads the active profile by name/path and applies its scope and cleaning rules; no site-specific constants (IRCC exclude patterns, canada.ca chrome regexes, department-slug neutralization) remain hardcoded in engine source.
- [x] **GEN-03**: No hardcoded absolute environment paths (e.g. venv interpreter paths) exist anywhere in source, docstrings, README, or QC_RUNBOOK; the tool runs via a standard documented install.
- [ ] **GEN-04**: Invalid or missing profile config fails fast with a clear, actionable error message.

### Built-in Default Profile (PROF)

- [ ] **PROF-01**: An IRCC/canada.ca site profile ships with the package and reproduces the current crawl scope, chrome-stripping, and labeling behavior.
- [ ] **PROF-02**: A documented template/example profile is provided so a user can copy it to target their own authoritative source.

### Packaging & Distribution (PKG)

- [x] **PKG-01**: The crawler installs as a Python package via Poetry (`pyproject.toml` + `poetry.lock`) with pinned dependencies.
- [ ] **PKG-02**: A console entry point exposes the pipeline commands (crawl / apply-verdicts / completeness / report) as a single installed CLI runnable from any directory.
- [ ] **PKG-03**: An MIT `LICENSE` file is present, and attribution / robots / source-ToS / non-commercial-use notes are documented.

### Public-Safe Repository (SAFE)

- [x] **SAFE-01**: The repository contains no PII, secrets, or credentials; `.gitignore` excludes personal/trial corpora and crawl outputs.
- [x] **SAFE-02**: A repeatable check (script or documented procedure) verifies the tree is publish-safe (no absolute home paths, no secrets, no personal data) before sharing.

### Agent Integration (AGENT)

- [x] **AGENT-01**: The CLI emits a stable, documented JSON contract (machine-readable stats/results on stdout) that any CLI agent can parse when shelling out.
- [x] **AGENT-02**: A portable agent skill file (CLI-agnostic) is provided that lets Antigravity/Codex/Claude/Copilot/Gemini agents drive the pipeline via the documented CLI/JSON contract.

### Documentation (DOCS)

- [ ] **DOCS-01**: A generalized README covers install, configuring a new site profile, running the full pipeline, and interpreting outputs — not IRCC-specific.
- [ ] **DOCS-02**: The QC_RUNBOOK is generalized (no absolute paths, no single hardcoded example dependency) into a config-authoring + QC guide usable for any source.

## Future Requirements

Deferred to a later milestone:

- Publishing the package to PyPI / a release pipeline.
- Multiple concurrent profiles / a profile registry beyond file-based configs.
- Non-HTML source adapters beyond the current PDF handling (e.g. DOCX, sitemap-driven discovery) as first-class profile options.

## Out of Scope

- Changing crawl/QC/completeness *behavior* for the IRCC default profile — this milestone is a refactor/productization, behavior parity is required (excluded: feature changes to grounding/eval semantics).
- Building the downstream corpus index / document agents — those belong to the application, not the shareable crawler tool.
- A hosted/service version of the crawler — the deliverable is a local, self-run CLI tool.
