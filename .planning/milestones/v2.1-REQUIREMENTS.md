# Requirements: v2.1 — Authoritative Corpus Ingestion

Use the shipped `corpus-crawler` (v2.0) to ingest the relevant authoritative resources into the project's local (git-ignored) corpus, then run the QC pipeline so the corpus is complete, in-scope, and groundable.

## Active

- [x] **CRWL-01**: All relevant authoritative source families are crawled into the local `corpus/` via `corpus-crawler` (IRCC Express Entry post-ITA guidance, IRPA, IRPR, language-requirements PDI, medical-requirements PDI, ECA PDI), each with the IRCC profile and a documented run config.
- [x] **CRWL-02**: Each crawled document has a QC eval (`<doc>.eval.json`) with a relevance score, keep/prune/drop verdict, and groundable `must_contain` facts; `crawler.eval_runner` enforces them (no failing evals) and `apply-verdicts` quarantines `drop` docs into `_dropped/`.
- [x] **CRWL-03**: A completeness sample + `REPORT.md` is generated per source family; every family's report is overall PASS (in-scope, complete, groundable), and a top-level ingestion summary aggregates the corpus stats.

## Out of Scope

- Re-indexing into the FTS5 search DB / chunking — separate concern from the crawl ingestion (revisit if needed).
- Crawling sources outside the authoritative set (third-party/blog content is non-authoritative per PROJECT.md).
- Programs other than post-ITA Express Entry PR (PNP, sponsorship, study/work permits) — excluded by the IRCC profile scope.
