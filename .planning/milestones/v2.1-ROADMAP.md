## Active Milestone

### v2.1 — Authoritative Corpus Ingestion

> 🚧 ACTIVE — defined 2026-06-10. Continues phase numbering from v2.0 (starts at Phase 18).

**Why:** v2.0 productized the crawler; v2.1 *runs* it. Use the shipped `corpus-crawler` to
ingest all relevant authoritative resources into the project's local (git-ignored) `corpus/`,
then enforce the QC pipeline so the corpus is complete, in-scope, and groundable.

#### Phases

- [x] **Phase 18: Ingest Authoritative Sources** - Crawl all relevant source families (IRCC Express Entry post-ITA guidance, IRPA, IRPR, language-requirements PDI, medical-requirements PDI, ECA PDI) into `corpus/<family>` via `corpus-crawler` with the IRCC profile.
- [x] **Phase 19: QC, Verdicts & Completeness Reports** - Write + enforce per-doc QC evals, apply drop verdicts, sample completeness, and generate a PASS REPORT.md per family plus a top-level ingestion summary.

#### Phase Details

### Phase 18: Ingest Authoritative Sources

**Goal**: All relevant authoritative source families are crawled into the local `corpus/` via `corpus-crawler`, each with the IRCC profile and a recorded run config (seed / source-type / depth / max-pages / include).
**Requirements**: CRWL-01
**Success Criteria**:

  1. `corpus/` contains a subdirectory per source family with recorded `<doc>.md` files (frontmatter: url, title, source_type, crawl_date, label).
  2. IRPA and IRPR full texts are captured; Express Entry guidance, language, medical, and ECA trees are captured within their include scope.

### Phase 19: QC, Verdicts & Completeness Reports

**Goal**: Each crawled document is QC-evaluated and enforced; drop verdicts applied; completeness sampled; a PASS REPORT.md per family + a top-level ingestion summary.
**Requirements**: CRWL-02, CRWL-03
**Success Criteria**:

  1. Every recorded doc has a `<doc>.eval.json`; `crawler.eval_runner` passes (no failing evals); `apply-verdicts` quarantines `drop` docs into `_dropped/`.
  2. `corpus-crawler completeness` + `report` produce an overall-PASS REPORT.md per family; a top-level summary aggregates corpus stats.
