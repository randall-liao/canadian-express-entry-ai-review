## Artifacts this phase produces (defined here, implemented in Plans 02–03)

New module `crawler/dupaudit.py` — runnable as `python -m crawler.dupaudit corpus/ [--json] [--overlap-threshold 0.95] [--out reports/]` (NOT a `corpus-crawler` subcommand; productization is DUP-05/06, out of scope).

Public symbols (the contract this plan must declare):
- `body_of(text: str) -> str` — file text minus YAML frontmatter (mirrors `eval_runner._strip_frontmatter`).
- `body_hash(text: str) -> str` — `sha1` of the body (matches `crawler/pipeline.py:115`).
- `live_docs(corpus: Path) -> Iterator[tuple[Path, str]]` — the 752-filter enumerator.
- `@dataclass Doc` — fields: `path: Path`, `relpath: str`, `family: str`, `url: str`, `title: str`, `body: str`, `body_hash: str`, `body_len: int`, `passed_qc: bool`.
- `parse_doc(path, text, profile, corpus_root) -> Doc`.
- `exact_edges(docs) -> list[tuple[int,int]]`, `url_edges(docs) -> list[tuple[int,int]]`, `overlap_edges(docs, threshold=0.95) -> list[tuple[int,int]]`.
- `class UF` (union-find) and `cluster(n: int, edges) -> list[list[int]]` (components of size ≥2).
- `cluster_signals(components: list[list[int]], edges_by_signal: dict[str, list[tuple[int,int]]]) -> list[set[str]]` — for each component, the set of detector names ("exact"/"url"/"overlap") whose edges fell inside it. This is the Plan-02 producer for `Cluster.signals` (keeps the `signals` assertion in `TestCluster` satisfiable within Wave 2, before `audit()` assembles full `Cluster` records in Plan 03).
- `@dataclass Cluster` — fields: `members: list[int]`, `signals: set[str]`, `canonical_idx: int`.
- `select_canonical(members: list[Doc]) -> tuple[int, dict[int,str]]` — returns canonical index + per-member reason string.
- `@dataclass AuditResult` — fields: `live_docs: int`, `clusters: list[dict]`, `exact: int`, `url: int`, `overlap: int`.
- `audit(corpus: Path, overlap_threshold: float = 0.95) -> AuditResult`.
- `render_markdown(result: AuditResult) -> str`, `render_json(result: AuditResult) -> dict`.
- `main(argv: Sequence[str] | None = None) -> int` — `--json` envelope command name `"audit-duplicates"`.

Report output paths (written at runtime by Plan 03, NOT under `corpus/`):
- `reports/duplicate-audit.md` (human report)
- `reports/duplicate-audit.json` (machine sidecar)

Test module: `crawler/tests/test_dupaudit.py` with fixture `_make_dup_corpus(tmp)` and classes
`TestEnumerate, TestExact, TestUrl, TestOverlap, TestCluster, TestCanonical, TestReport, TestPublishSafe, TestReadOnly, TestJson`.
