<objective>
Implement the cross-family duplicate DETECTION engine inside `crawler/dupaudit.py`: live-doc
enumeration, frontmatter parsing, the three independent duplicate signals (exact content-hash,
same canonical URL, high text-overlap), union-find clustering of those signals, and deterministic
canonical-copy selection. This turns the RED detector tests from Plan 01 GREEN.

Purpose: Detection is the heart of the phase — it must reproduce the crawler's own dedup semantics
(body-only `sha1`, the crawler's `normalize_url`, the repo's `check_doc` QC judgement) so the audit
is consistent with how the corpus was ingested, and must be deterministic so Phase 21 deletes the
right copy.
Output: A fully implemented detection/clustering/selection core (`live_docs`, `parse_doc`,
`exact_edges`, `url_edges`, `overlap_edges`, `UF`, `cluster`, `select_canonical`).
</objective>
