<objective>
Make the zero-cluster re-check GREEN and wire the CLI so the tool is runnable as
`python -m crawler.dupclean`. The re-check re-enumerates the cleaned live corpus
and runs ONLY the fast exact+URL detectors (skipping the ~9-minute O(n^2) overlap
detector, which would spuriously re-report the retained overlap-only set). The CLI
exposes --apply / --include-overlap / --json / --out and emits the frozen
contract.envelope in --json mode.

clusters", correctly scoped to the duplicates we resolved) and make the tool
operable for the real-corpus run in Plan 05, with machine-readable output
consistent with Phase 20's dupaudit contract.
Output: A complete, CLI-operable crawler/dupclean.py; the full unit suite GREEN.
</objective>
