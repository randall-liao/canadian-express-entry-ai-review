# Milestone v3.0 — Grounded Answer Layer · Audit

**Goal:** Bring the answer half into the shareable repo — FTS5 retrieval + a fail-closed grounding
gate + the personalized Layer-1 document checklist + portable document agents — producing cited,
grounded answers about which PR documents the applicant needs, with PII kept strictly local.

**Acceptance bar (locked):** grounding-by-construction, fail-closed — every factual claim carries a
citation that resolves to a real corpus chunk AND whose verbatim quote is a substring of that chunk;
any uncited/unresolvable/quote-mismatch claim fails the entire output. The gate doubles as the eval
harness.

**Verdict: ACHIEVED — `tech_debt`** (all 7 requirements satisfied, 0 blockers; 3 low-severity,
mostly pre-existing tech-debt items carried forward for review).
