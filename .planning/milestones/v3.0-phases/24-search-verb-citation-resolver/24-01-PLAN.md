<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `search(query)` → FTS5 `MATCH` | **The primary attack surface of the phase.** `query` is fully untrusted (it originates from an agent / end user). It must never reach SQLite as raw text. |
| `search()` → `chunks`/`chunks_fts` (read-only) | SELECT-only over the Phase-23 DB. No write path exists in this phase, so there is no tampering/integrity surface against the index here. |
| `search()` → returned hits | Hits expose only corpus chunk text + the five PII-free citation fields the Phase-23 builder stored (no `personal/` is ever read). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Tampering (injection) | untrusted query → FTS5 `MATCH` | mitigate | `_to_match()` tokenizes (`re.findall(r"\w+")`) + per-term double-quotes so R30(3), apostrophes, colons, and bare OR/AND/NEAR become LITERAL terms; the escaped string is bound to `MATCH ?` (parameter-bound, never f-string). No fts5 syntax error, no operator/column-filter injection (RET-02 SC3 / RETRIEVAL.md P2). |
| T-24-02 | Denial of Service | unbounded / expensive query | mitigate | `LIMIT ?` is parameter-bound and capped (default 10) so a hostile query cannot stream the whole index; an empty / all-punct query raises `EmptyQuery` instead of running an empty MATCH (RET-02 SC3). |
| T-24-03 | Information disclosure | search result payload | mitigate | `search()` reads only `corpus/`-derived `chunks` rows (corpus text + PII-free citation metadata); it never opens `personal/`. The Phase-23 DB carries no PII/vectors by construction (RET-01 SC4). |
| T-24-08 | Tampering / availability | host SQLite lacking FTS5 | mitigate | `search()` calls the existing `_probe_fts5(con)` BEFORE any query; a non-FTS5 host raises `FTS5Unavailable`, which Plan 03 maps to a loud missing_dependency / exit 3 (RETRIEVAL.md P1). |
| T-24-SC | Tampering | dependency supply chain | accept | No package installs — stdlib only (`re` + `sqlite3`, both already imported). Zero new runtime deps; Package Legitimacy Gate N/A (no install tasks). |
</threat_model>
