<objective>
Build the pure-stdlib grounding compute module `crawler/grounding.py` — the fail-closed
heart of the GND-01/GND-02 gate — plus its unittest suite. The module parses a structured
answer object, checks ONLY `claims[]`, resolves each citation in-process via the shipped
`searchindex.resolve()` (GND-01), verifies the verbatim `quote` is a whitespace/case-normalized
substring of a resolving chunk, and returns a fail-closed whole-answer verdict (GND-02). It also
renders a passing answer with claim+quote side-by-side for human review (SC5 honesty boundary).

Purpose: Isolate all deterministic grounding logic in one pure, unit-testable module so the CLI
verb (Plan 02) and eval harness (Plan 03) are thin consumers. This is the contract every later
producer (Phases 26/27) emits into.
Output: `crawler/grounding.py` + `crawler/tests/test_grounding.py` (GREEN).
</objective>

## Locked decisions baked into this plan (no re-litigation)

- The gate calls `searchindex.resolve(db, chunk_id)` IN-PROCESS per citation — never shells out to
  `search --cite`, never re-implements resolution. `resolve()` already returns the verbatim chunk
  dict or `None` on miss/sha-drift (fail-closed).
- Quote normalization reuses `eval_runner._norm` semantics EXACTLY: `re.sub(r"\s+"," ",s).strip().lower()`
  — whitespace-collapse + lowercase ONLY. NO Unicode folding, NO curly→straight conversion, NO
  markdown stripping. The verbatim-substring check is `_norm(quote) in _norm(resolved_chunk_text)`.
  Loosening this silently widens the grounding guarantee — forbidden.
- Honesty boundary (locked v3.0): the gate guarantees citation RESOLVABILITY + VERBATIM-QUOTE
  substring, NOT semantic entailment/faithfulness (VAL-01/02 deferred — needs a model, violates the
  no-vectors/no-cloud constraint). State this in the module docstring.
- Do NOT modify `crawler/searchindex.py` (resolve/search/build_index are shipped & GREEN) — the gate
  is a CONSUMER. Reuse `eval_runner._norm` semantics (copy the 1-line helper verbatim; importing it
  is also acceptable).

## Artifacts this phase produces (this plan's slice)

New file `crawler/grounding.py` exporting:
- `InvalidAnswer(ValueError)` — malformed/missing-shape answer; the CLI (Plan 02) maps it to `invalid_input`/exit 2.
- `_norm(s: str) -> str` — whitespace-collapse + lowercase normalizer (copied from `eval_runner._norm`).

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| producer → grounding compute | Untrusted structured-answer dict (claim ids/quotes/citations) crosses into `check_answer`. |
| compute → SQLite index | Citation ids are passed to `searchindex.resolve`, which binds them positionally (read-only). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-25-01 | Spoofing | fabricated citation id | mitigate | `searchindex.resolve` checks every id against the real index; unknown → `None` → `unresolvable` (fail-closed, GND-01). |
| T-25-02 | Tampering | decorative citation that resolves but doesn't contain the claim quote | mitigate | hard verbatim-quote substring check `_norm(quote) in _norm(chunk.text)`; any mismatch → `quote_not_in_chunk`. |
| T-25-03 | Tampering (injection) | malicious citation id string | accept | `resolve()` binds `chunk_id` positionally (`WHERE chunk_id = ?`, no f-string, no `MATCH`) — no injection surface; verified in searchindex.py:534-535. |
| T-25-04 | Tampering | stale/edited chunk row reused as citation | mitigate | `resolve()` recomputes `chunk_sha` and returns `None` on drift — treated as a miss (fail-closed). |
| T-25-05 | Information disclosure | abs-path/secret embedded in rendered markdown | mitigate (deferred to Plan 02) | `render_answer` adds no abs paths; the RPT-03 `scan_text` render-then-gate is wired in Plan 02 before any write. |
| T-25-SC | Tampering | npm/pip/cargo installs | accept (vacuous) | Zero new dependencies — stdlib only (RESEARCH Package Legitimacy Audit, N/A). No install task in this plan. |
