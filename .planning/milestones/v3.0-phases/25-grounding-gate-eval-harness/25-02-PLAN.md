   - A *grounding* failure (any uncited / unresolvable / quote-mismatch claim) is an EXPECTED verdict
     → envelope `ok:true`, `result.verdict:"fail"`, **exit 1**, render NOTHING user-facing. Mirror
     `_cmd_report` (cli.py:223-240) and `dupclean.py:597` (`return 1 if verdict=="fail" else 0`).
   - A *publish-safety* hit in the rendered output (RPT-03 render-then-scan) → `ok:false`,
     `error.type:"internal_error"`, **exit 4**. Mirror `dupaudit.py:614-629` / `dupclean.py:575-589`.
     This matches ROADMAP SC3's "exit 4". Do NOT add a new error type or a new exit code. Use the
     existing `contract.INTERNAL_ERROR` / `contract.EXIT_INTERNAL_ERROR` constants (never a bare `4`).
   - Malformed stdin / missing-key answer / non-file `--db` → `ok:false`, `invalid_input`, **exit 2**
     (`contract.INVALID_INPUT` / `contract.EXIT_INVALID_INPUT`).
2. **Contract is additive-only:** `SCHEMA_VERSION` stays `"1.0"`, the five envelope keys are unchanged,
   exit codes 0/1/2/3/4 are unchanged. The ONLY change is one new `command` value `ground` and
   additive CONTRACT.md docs.

| Boundary | Description |
|----------|-------------|
| producer → CLI (stdin) | Untrusted structured-answer JSON arrives on `sys.stdin` for `_cmd_ground`. |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-25-06 | Information disclosure | PII/secret/abs-path in a shareable rendered answer | mitigate | RPT-03 render-then-gate: `check_publish_safe.scan_text` over the rendered bytes BEFORE write; any hit → `ok:false`/`internal_error`/exit 4, write nothing (SC3). |
