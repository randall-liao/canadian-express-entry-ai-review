## Locked decisions baked into this plan (no re-litigation)

- **Eval driver scope = gate-over-fixtures (NOT agent-over-questions).** No document agent exists
  until Phase 27, so each `questions.jsonl` line is a COMPLETE stored answer object (the gate's stdin
  schema) plus an `expect`/`must_abstain` marker. The eval runs the per-claim gate over each stored
  answer; it does NOT generate answers. Keep the loader generic so Phase 27 can later feed agent output
  through the same gate.
- **The result shape is LOCKED to `eval_runner`'s `{total, passed, failed, failures}`** (mirror
  `eval_runner.main:135-139`); overall exit is `1 if failed else 0` (mirror `eval_runner.main:150`).
- **`must_abstain` correctness:** a `must_abstain` line MUST carry an empty `claims[]`. A `must_abstain`
  line that carries any claims is an eval FAILURE (`should_have_abstained`). A non-abstain line is
  graded by the normal `check_answer` gate.
- **Fixture is TRACKED + PII-FREE (the #1 PII-leak temptation).** Location `crawler/eval/questions.jsonl`
  — this path is NEITHER git-ignored NOR a `CORPORA_PREFIXES` path, so it is safe to track (it CANNOT
  live under `personal/`/`trial/`/`corpus_new/`, all of which are ignored/flagged). Use ONLY synthetic,
  public, corpus-derived content: no names, dates, addresses, abs paths, or token-shaped strings. The
  grounded lines' `claims[].text` is corpus-derived (the corpus has no PII); the quotes are copied
  VERBATIM from `resolve()['text']`.
- **Unit-test against a SYNTHETIC tiny index** (mirror `_IndexCase`/`TestResolve`); guard the real-corpus
  eval with `@unittest.skipUnless(Path("corpus/index.db").is_file(), …)` (mirror `TestRealCorpus`).
- Eval mode adds NO render/write (it is a check); only single-answer mode (Plan 02) renders.
- Producers MUST copy each grounded `quote` VERBATIM from the resolved chunk's `text` (obtain it via
  `.venv/bin/python -m crawler.cli --json search --cite <id> --db corpus/index.db` → `result.chunk.text`).
  VERIFIED real example: `chunk_id` `police-certificates/south-africa.md#005` resolves to text beginning
  `Certificates from Ideco Biometrics are **not** valid for immigration purposes.` (note the `**not**`
  markdown — copy it verbatim; `_norm` does NOT strip markdown).
