<objective>
Author three thin, CLI-agnostic document-agent skills — police certificate, language test, and ECA —
each teaching any CLI agent to retrieve its single requirement from the corpus via
`corpus-crawler --json search`, copy a verbatim generic quote, emit a PII-free cited claim, and pipe
the answer through `corpus-crawler --json ground` (abstaining when nothing resolves). The
police-certificate agent additionally enforces the residence-history no-leak backstop
(`--family guidance` + per-country relpath skip). All three defer the schema/loop to the shared
`skills/document-agents/_contract.md`. [CHK-03 SC1, SC2]

Purpose: Three of the six document agents, proving the generic search→quote→ground→abstain pattern.
Output: `skills/document-agents/{police-certificate,language-test,eca}.md`.
</objective>
