<objective>
Author the new sixth document agent — the centerpiece of Phase 27 — that verifies an Express Entry
employment/reference letter (the PROOF-OF-WORK-EXPERIENCE letter supporting the skilled
work-experience claim). It teaches any CLI agent to bake a SHORT query that lands the
work-experience-letter requirements chunk, copy a SEPARATE verbatim quote for EACH required element,
emit one generic PII-free claim per element, and pipe the assembled answer through
`corpus-crawler --json ground` to verdict:"pass" — abstaining for any element the corpus cannot
ground, and never confusing this letter with the arranged-employment job-offer letter. All
personalization (employer name, dates, salary, applicant name) stays in basis[]. [CHK-03 SC4]

Purpose: Deliver the user's primary request — a gated, cited employment-reference-letter verifier —
proving every required element is grounded to the corpus, never hardcoded.
Output: `skills/document-agents/employment-reference-letter.md`.
</objective>
