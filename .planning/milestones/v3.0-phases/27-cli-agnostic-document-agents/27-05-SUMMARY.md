## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 — Bug] Static "no-inlined-volatile-values" year regex would false-positive on the `U+2019` codepoint reference in `eca.md`.**
- **Found during:** Task 3 (authoring the static grep gate).
- **Issue:** The plan's naive year pattern `\b20[0-9]{2}\b` matches the `2019` inside `U+2019` — the Unicode codepoint reference in `eca.md`'s curly-apostrophe hazard note (which plan-check W1 itself motivated documenting). The plan's literal `<verify>` one-liner (line 206) includes that pattern and would therefore `exit 1` against the legitimate, clean skill. A codepoint reference is documentation of an encoding hazard, NOT an inlined requirement value.
- **Fix:** Implemented the gate's calendar-year check with a precise regex — `(?<![A-Za-z0-9+])(?:19|20)[0-9]{2}(?![0-9])` — whose negative look-behind excludes `U+`-style codepoint references while still catching a real inlined year. Confirmed the only naive-year hit across all six skills is exactly `U+2019` in `eca.md`; with the precise regex all six agent skills are CLEAN and `TestSkillsStaticGate` passes (7/7).
- **Files modified:** crawler/tests/test_document_agents.py
- **Commit:** 96e55fe
