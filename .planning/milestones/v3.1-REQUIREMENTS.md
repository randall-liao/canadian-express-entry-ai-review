# Requirements: PR Review Agents — Canadian PR Application Guide

**Defined:** 2026-06-24
**Milestone:** v3.1 — Express Entry Document-Agent Expansion
**Core Value:** Every answer about which documents are required and whether the user has them right is grounded in and cited from an authoritative source — the system never guesses on immigration requirements.

## v3.1 Requirements

Requirements for milestone v3.1. Each maps to a roadmap phase.

> **Acceptance bar (inherited, locked):** *grounding-by-construction* — every factual
> claim a document agent emits must carry a citation that resolves to a real corpus
> chunk AND whose verbatim quote is a normalized substring of that chunk; any
> uncited/unresolvable/quote-mismatch claim fails the entire output (fail-closed). New
> agents add NO new trust-path code — they drive the frozen Phase 24/25 primitives.

### Document-Agent Coverage

- [x] **CHK-04**: Every mandatory and mandatory-if-applicable document in the IRCC Express Entry e-APR completeness-check checklist (plus the cross-cutting translation requirement) has a portable, CLI-agnostic markdown document agent that emits only grounded, cited claims (subject to GND-02), expanding the pack from 6 to 22 agents. Each agent bakes a short query, selects its requirements chunk by a non-volatile marker (never `hits[0]` blindly), keeps all PII in `basis[]`, and is proven by the conformance harness to retrieve a chunk that verbatim-grounds the quote it cites.
