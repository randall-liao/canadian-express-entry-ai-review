# Roadmap: v3.1 — Express Entry Document-Agent Expansion

**Milestone:** v3.1
**Created:** 2026-06-24
**Status:** Shipped (2026-06-24)
**Core Value:** Every answer about which documents are required is grounded in and cited from an authoritative source.

## Context

v3.0 shipped the Grounded Answer Layer with **six** portable document agents
(police-certificate, language-test, eca, proof-of-funds, medical, and the
employment-reference-letter agent). The IRCC Express Entry e-APR completeness-check
PDI defines a much larger document set — passport, job offer, proof of studies,
marital-status documents, dependant documents, forms, translation, and more — none
of which had a dedicated review agent. v3.1 closes that gap, bringing the pack to
the full e-APR document set while preserving the grounding-by-construction acceptance
bar and the PII boundary.

## Phases

### Phase 28 — Express Entry Document-Agent Expansion ✅

**Requirement:** CHK-04
**Goal:** Add a portable, CLI-agnostic markdown document agent for every remaining
mandatory / mandatory-if-applicable e-APR document type (plus translation), each
grounded-by-construction against the real corpus and proven by the conformance
harness.

**Delivered (16 new agents, 6 → 22 total):**

- **Mandatory for all:** `passport`, `digital-photos`, `translation`
- **Mandatory if applicable:** `job-offer`, `proof-of-studies`,
  `certificate-of-qualification`, `birth-certificate`, `marriage-certificate`,
  `common-law-union`, `divorce-certificate`, `death-certificate`,
  `adoption-certificate`, `use-of-representative`
- **Other documents:** `relative-in-canada`, `other-name`, `authority-to-release`

**Approach:** Each agent replicates the Phase-27 employment-letter pattern — a baked
2–4 token query plus a `contains_marker` selection rule (resolve hits in BM25 order,
take the first whose text contains a non-volatile requirement phrase) that lands the
document's requirements chunk in the canonical completeness-check PDI. Generic
requirement labels go in `claims[]`; all personalization stays in `basis[]`. No new
trust-path code: agents drive the frozen `corpus-crawler --json search/ground`
primitives.

**Verification:**

- Every `(query, marker, quote)` triple verified against the live `corpus/index.db`:
  the query+rule selects the cited chunk and the quote verbatim-grounds.
- Conformance harness (`crawler/tests/test_document_agents.py`): **19 tests + 22
  subtests pass** against the real corpus — the retrieve-what-you-cite proof now
  covers all 22 agents; `run_eval` grounds all 24 fixture lines clean (failed==0);
  rendered bytes publish-safe; static gates (no chunk-id/year/amount/duration inlined,
  no bare-python, contract-linked) pass.
- Change-relevant modules (grounding, checklist, searchindex, cli, document_agents):
  **202 passed**.
- End-to-end shipped-CLI check confirmed (translation agent grounds its rank-2
  requirements chunk → `verdict:pass`, exit 0, output to git-ignored `personal/output/`).
