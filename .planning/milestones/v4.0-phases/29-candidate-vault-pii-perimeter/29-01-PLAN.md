  <files>crawler/paths.py, crawler/checklist.py, crawler/cli.py, crawler/tests/test_paths.py</files>
  <behavior>
    - repo_root() returns the repo root anchored at Path(__file__).resolve().parents[1]
      (crawler/ is one level below root), matching the existing cli._personal_root anchor.
    - repo_personal_root() returns repo_root()/"personal" resolved, UNCONDITIONALLY
      (never consults $PR_PERSONAL_DIR) — this is the frozen ground/checklist write-gate anchor.
    - legacy_personal_dir() returns Path(os.environ.get("PR_PERSONAL_DIR", "personal"))
      VERBATIM (relative "personal" default) — identical to today's checklist.personal_dir.
    - personal_root(explicit=None) precedence: explicit arg > $PR_PERSONAL_DIR >
      repo_personal_root() when running_from_repo_checkout() else
      platformdirs.user_data_path("pr-review-agents")/"personal"; always returns a resolved
      absolute Path. platformdirs is imported LAZILY inside the fallback branch so paths.py
      imports even when platformdirs is absent.
    - running_from_repo_checkout() is True iff repo_root()/".git" exists.
    - is_within(root, target): True iff target.resolve()==root.resolve() or root.resolve()
      in target.resolve().parents.
    - resolve_within(root, *parts) raises PathEscapeError when any part is absolute or
      contains "..", or when the resolved join is not is_within(root); otherwise returns the
      resolved child Path. Symlink escape: a symlink under root pointing outside is caught
      because .resolve() follows it before the containment check.
    - safe_candidate_id(raw) lowercases, maps non [a-z0-9-] runs to "-", strips edges, and
      raises PathEscapeError on empty result (never accepts names/UCI/passport-shaped input).
    - candidate_root(candidate_id, explicit=None) == personal_root(explicit)/"candidates"/safe_candidate_id(candidate_id).
  </behavior>
