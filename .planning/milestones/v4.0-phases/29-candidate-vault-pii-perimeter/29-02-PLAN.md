<objective>
Build the candidate vault module: a private SQLite index (`vault.sqlite`) plus
content-addressed raw files under `personal/candidates/<id>/files/raw/`, mirroring the
corpus-DB pattern (stable logical IDs, content hashes, metadata tables) but on the
PRIVATE side of the boundary. This plan stores the CRS factor breakdown + ITA
round/cutoff (VAULT-01), ingests raw PDFs/images as content-addressed files with a
minted private `evidence_id` (VAULT-02), and encodes the invariant that a candidate
`evidence_id` can never be mistaken for a corpus `citation_id` (VAULT-03).

Purpose: This is the PII-bearing store the whole milestone protects. It must never
write outside the vault, never store raw files as SQLite BLOBs, and never emit
original filenames or absolute paths.
Output: `crawler/models/vault.py`, `crawler/vault.py`, a synthetic example, tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user file / YAML → vault store | Untrusted document bytes + profile YAML enter the private DB. |
| vault write path → filesystem | Every write must land inside the candidate root only. |
| vault ids ↔ corpus citation ids | Two ID namespaces must never be interchangeable. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-04 | Tampering (path traversal) | `import_document` dest path | mitigate | Dest always via `resolve_within(candidate_root, ...)`; forged `..` raises PathEscapeError. |
| T-29-05 | Information disclosure | `original_name` / abs paths | mitigate | original_name stored in DB only; summaries + returns are PII-light (ids/counts/status). |
| T-29-06 | Spoofing/Elevation | evidence_id vs citation_id confusion | mitigate | `ev_` namespace + `is_evidence_id`/`is_citation_id` predicates proven disjoint (VAULT-03). |
| T-29-07 | Tampering (deserialization) | `import_profile_yaml` | mitigate | `yaml.safe_load` only; PII-free error messages (field/type, never value). |
| T-29-08 | Information disclosure | corpus contamination | mitigate | Vault writes never touch corpus/index.db; candidate text never enters corpus/. |
</threat_model>
