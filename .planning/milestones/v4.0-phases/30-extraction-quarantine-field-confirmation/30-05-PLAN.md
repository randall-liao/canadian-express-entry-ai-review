<objective>
Close the two milestone-level INTEGRATION BLOCKERs that prevent the shipped end-to-end CLI pipeline from producing a `SUBSTANTIATED` verdict for a legitimately-qualified applicant, even though every phase passes in isolation. The defect is entirely in the EXTRACTION -> AUDITOR/REGISTRY seam (Phase 30 owns extraction); the auditor core, grounded conversion tables, grounding gate, spouse-mode fix, caps, and arranged-employment guard are all correct and MUST NOT be touched.

Two BLOCKERs + one supporting gap + one blind spot:
- BLOCKER A (evidence mis-linked, P30->P32/33): `_resolve_factor` links every value to the alphabetically-first factor of the field's group (`SELECT ... WHERE factor_group=? ORDER BY factor_id LIMIT 1`), so all language values land on `core.age`, all nomination values on `additional.french`, etc. The specific-factor-keyed auditor read (`audit_eligible_values(vault, factor_id)`) then sees empty evidence -> `GAP missing_evidence`.
- BLOCKER B (test_type vocabulary mismatch, P30->P31): the extractor normalizes to `IELTS`/`CELPIP` while the registry accepted-enum + conversion tables key on `IELTS General Training`/`CELPIP-General` -> `GAP unaccepted_test_type`.
- Supporting gap: no `date_of_birth` field / identity doc_type exists, so `core.age` is unsubstantiable through the real pipeline regardless of linkage.
- Blind spot: `test_full_audit_integration.py` bypasses the real seam by calling `add_extracted_value(... factor_id=<grid id> ...)` with hard-coded `test_type`/doc_types/fields; no test exercises real `vault extract` -> `audit`.

Purpose: make the real extraction seam feed each factor the CORRECT, COMPLETE, registry-vocabulary evidence, and lock it with a real end-to-end regression + an anti-drift gate — so a genuinely-qualified applicant reaches SUBSTANTIATED through the actual CLI, and this class of seam bug cannot silently return.

Output: a shared canonical test_type vocab module, a rewritten deterministic factor-linkage + DOB extraction path, a CLI `--factor` disambiguation override, and three new test files (drift gate, real-seam linkage/DOB, real-seam E2E). The auditor verdict logic, `crs_audit`, the registry rules, and the vault/PII perimeter are UNCHANGED.
</objective>
