grounded current repeal row (with effective-date metadata) plus a distinct legacy/ITA-era
row (or documented gap) so Plan 31-04's deterministic guard can decide legacy applicability
strictly from grounded authority, never from prose.

including an explicit assertion that the arranged-employment repeal quote grounds.
