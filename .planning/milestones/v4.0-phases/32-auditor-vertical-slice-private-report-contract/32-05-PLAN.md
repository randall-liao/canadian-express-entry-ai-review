<objective>
Wire the slice to the operator and slam the PII door: an additive `vault audit` CLI verb
that runs the first-official-language audit and emits the PII-light envelope, plus the
privacy-perimeter tests + publish-safe coverage that make AUDIT-06 provable.

`vault audit --candidate <id> [--factor core.language.first] [--db corpus/index.db]`:
- On success (any of SUBSTANTIATED / GAP / AT-RISK / N/A), emits ONE five-key envelope with
  `command: "vault"` and a `result` that is the `PublicAuditEnvelope` (run id, per-factor
  verdicts, counts, generic corpus-cited `claims[]`, and the vault-RELATIVE private output
  path). This is `ok:true` — a grounded GAP/AT-RISK is a valid result, per the frozen
  contract's rule that a *verdict* is not an execution error.
- On `AuditGroundingError` (true grounding/system failure), emits `ok:false` with an
  `error` object and a documented non-zero exit code, and writes no report (SC5).
- The human view (applicant values, factor-card detail) prints to STDERR only, exactly like
  the shipped `vault fields` verb — stdout in `--json` mode stays pure PII-light JSON.

Reuse the existing `command: "vault"` envelope name (this is a `vault` subverb, consistent
with `init`/`profile`/`import`/`fields`/`confirm`) so the frozen 5-key contract + its
command allowlist are untouched; document the new `vault audit` result shape in
`crawler/CONTRACT.md`. Covers AUDIT-02 (operator surface for the verdict) and AUDIT-06
(PII-light public output + report artifact publish-safety).

Output: `vault audit` in `crawler/cli.py`, a CONTRACT.md result-shape section, a publish-safe
coverage assertion, and two test files.
</objective>

|----------|-------------|
| `vault audit` → `--json` stdout | the machine-readable envelope crosses to an external agent; must be strictly PII-light |
| tracked repo tree ↔ vault report artifacts | a report/DB artifact must never be publishable if accidentally staged |

| T-32-10 | Tampering | publish-safe coverage of the new artifact | mitigate | confirm/extend `check_publish_safe` `VAULT_SUBTREES`/`VAULT_ARTIFACT_EXTS` so a tracked `output/crs-audit/*.json|.md` or `*.sqlite` trips `VAULT_ARTIFACT`; a regression test asserts the flag |
| T-32-13 | Repudiation | verdict-vs-error envelope semantics | mitigate | grounded GAP/AT-RISK/N/A → `ok:true` result (a valid verdict), grounding/system failure → `ok:false` + error + non-zero exit and no report, matching the frozen `contract.py` verdict-not-error rule (SC5) |
