<objective>
Surface any factor that is `SUBSTANTIATED` yet cannot be priced from grounded rows as an explicit
unresolved/unpriced item rather than a complete-looking result (COV-02). Today `run_full_audit` rolls
the total up with `sum(c.substantiated_points or 0 for c in cards if c.verdict == "SUBSTANTIATED")`,
so a `SUBSTANTIATED` card with `substantiated_points is None` silently contributes 0 with no visible
signal — a truthful-but-incomplete result. This plan adds a structural net: an additive
`points_unresolved` flag on the private card, a `counts["unpriced"]` tally on the PII-light public
envelope, and an explicit rendered line in the vault-only markdown report. The verdict itself stays
`SUBSTANTIATED` (narrow semantics preserved) and no point value is fabricated.

Purpose: Satisfy COV-02 (per D — locked decision: "Surface any still-unpriced substantiated factor as
unresolved"). Independent of plan 35-01's data (proven with a synthetic card), it catches every residual
unpriced case (e.g. second language at CLB≠9) even after 35-01 closes first language. This is the
no-false-completeness net that Phase 37 remediation later reads as an actionable unresolved item.
Output: an additive optional card field, an additive counts key, one report line, and a net-proving test.
</objective>
