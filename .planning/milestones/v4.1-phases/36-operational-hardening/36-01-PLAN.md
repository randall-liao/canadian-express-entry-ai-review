<objective>
Convert a missing / empty / unreadable / corrupt / content-drifted corpus index at `--db` from an
uncaught `sqlite3.OperationalError` → generic `internal_error`/exit-4-with-traceback into a stable,
PII-free, actionable refusal on the frozen contract vocabulary plus a specific reason code (HARD-01),
that exits non-zero, recommends the existing `index`/`doctor` recovery command, and writes no audit /
remediation / packet / database artifact (HARD-02).

Purpose: close the operational-hardening refusal gap on the shared audit path and PRODUCE the reusable
clean-refusal helper Phases 37 (remediation) and 38 (packet) consume on the same report-load/audit path.
Output: a new typed read-only preflight module + a reusable CLI refusal helper wired into `vault audit`.
</objective>

  <action>
Create `crawler/index_health.py`:

- Closed reason-code constants: `INDEX_OK="ok"`, `INDEX_MISSING="index_missing"`, `INDEX_EMPTY="index_empty"`,
  `INDEX_UNREADABLE="index_unreadable"`, `INDEX_CORRUPT="index_corrupt"`, `INDEX_DRIFTED="index_drifted"`.
- `_REQUIRED_TABLES = {"chunks", "chunks_fts", "meta"}`; `_DRIFT_SAMPLE = 64`.
- A frozen `@dataclass IndexHealth` with fields `status: str`, `reason: str`; methods `ok()` and
  `message(db)`. `message` returns:
  `f"corpus index unusable (reason={self.status}): {self.reason}. Recover: rebuild it with "
   f"'corpus-crawler --json index corpus/ --db {db}' then verify with 'corpus-crawler --json doctor'."`
  (the only path is the caller-supplied `--db`, matching the existing `not a file: {db}` precedent; no PII).
- `probe_index(db) -> IndexHealth`:
  1. `p = Path(db)`; `if not p.is_file(): return IndexHealth(INDEX_MISSING, f"no index file at {p}")`.
  2. `if p.stat().st_size == 0: return IndexHealth(INDEX_EMPTY, f"index file is empty (0 bytes): {p}")`.
  3. `con = sqlite3.connect(f"file:{p}?mode=ro", uri=True)` wrapped in try/except `sqlite3.OperationalError`
     → `IndexHealth(INDEX_UNREADABLE, "cannot open index read-only")`.
  4. In a try/finally that closes `con` — with the ENTIRE post-connect body wrapped in
     `try/except sqlite3.DatabaseError: return IndexHealth(INDEX_CORRUPT, "index tables unreadable")`
     (HIGH-1: this catches EVERY row/column-level malformation, incl. a `chunks` table missing `chunk_sha`
     or a truncated/"disk image malformed" file that only fails when row blobs are read — never an uncaught
     exception that re-raises the traceback this phase eliminates):
     - `names = {r[0] for r in con.execute("SELECT name FROM sqlite_master WHERE type IN ('table','view')")}`
       (a non-sqlite/corrupt file raises `sqlite3.DatabaseError: file is not a database` here → the wrapper
       returns `index_corrupt`).
     - `missing = _REQUIRED_TABLES - names`; if missing → `IndexHealth(INDEX_CORRUPT, f"missing index tables: {sorted(missing)}")`.
     - `n = con.execute("SELECT count(*) FROM chunks").fetchone()[0]`; `if not n: return IndexHealth(INDEX_EMPTY, "index has zero chunks")`.
     - `con.execute("SELECT count(*) FROM chunks_fts").fetchone()` (a malformed FTS vtable raises here → `index_corrupt`).
     - drift sample: `rows = con.execute("SELECT text, chunk_sha FROM chunks LIMIT ?", (_DRIFT_SAMPLE,))`;
       `for text, sha in rows: if searchindex.chunk_sha(text) != sha: return IndexHealth(INDEX_DRIFTED,
       "indexed chunk text drifted from its integrity fingerprint")`. (A missing `chunk_sha` column raises
       `DatabaseError` here → caught by the wrapper → `index_corrupt`.)
  5. Fall through → `IndexHealth(INDEX_OK, "index readable and consistent")`.
- Import `searchindex` lazily inside `probe_index` (or module-top; `searchindex` only pulls stdlib +
  dupaudit/profile which are cheap) to avoid heavy imports on a bare `crawler.index_health` import; prefer
  a local import of `chunk_sha` to keep the module import light, mirroring how cli.py lazy-imports searchindex.

Do NOT run `PRAGMA integrity_check` on the happy path (O(db)); table presence + drift sample suffice.
  </action>

def _require_readable_index(args, db):
    """Preflight the corpus index; return an exit code on refusal, else None.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller `--db` arg → corpus index reader | An untrusted/absent/corrupt path must fail closed with a clean refusal, never a traceback or a mutated/created DB |
| refusal message → stdout/stderr | Must be PII-free (only the caller's `--db` path + reason code + recovery hint) |
| refusal → vault | Must occur before any vault open/write so zero artifacts are produced |
