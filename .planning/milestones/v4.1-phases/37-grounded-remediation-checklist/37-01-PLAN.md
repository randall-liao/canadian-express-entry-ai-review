  <action>
Create `crawler/remediation.py`:

- `class RemediationError(ValueError)`: PII-safe message (reason token only) — raised by `build_remediation`
  on registry drift (a cited id with no current quote) and reused by the Plan-37-02 writer/CLI.

Models (pydantic v2, `extra="forbid"`, `from __future__ import annotations`):
- `RemediationCitation(citation_id: str [pattern relpath#ordinal, reject ev_], quote: str)`.
- `PrivateRemediationItem`: `factor_id`, `factor_group: FactorGroup | None`, `verdict: Verdict`,
  `reason_code: str | None`, `finding_kind: Literal["gap","at_risk","unpriced"]`,
  `substantiated_points: int | None`, `score_delta: int | None`, `points_unresolved: bool`,
  `evidence_ids: list[str]`, `citations: list[RemediationCitation]`, `action: str`.
- `PrivateRemediationChecklist`: `source_audit_run_id: str`, `candidate_id: str`,
  `items: list[PrivateRemediationItem]`, plus counts helpers. (PII-bearing; vault-only.)
- `PublicRemediationSummary` (PII-light): `run_id: str`, `source_audit_run_id: str`,
  `item_count: int`, `counts: dict[str,int]` (by finding_kind + verdict), `private_output_path: str`
  (vault-relative validator). NO ev_/applicant value.

`SCREENING_NOTICE`: reuse `audit_report.SCREENING_NOTICE` (import it) so remediation renders the SAME
screening framing (do not fork the text).

Action templates: a module-level `_ACTION_TEMPLATES: dict[str, str]` keyed by reason code + a
`_DEFAULT_ACTION_BY_KIND: dict[str,str]` fallback per finding_kind. Each is a `str.format`-style template
with a `{factor}` placeholder (and NOTHING volatile — no CLB/points/date literal). Cover the common
reasons: missing_evidence, missing_eca, not_audit_eligible, below_threshold, below_tier, unmet_component,
expired_test, expired_eca, expired_nomination, unresolved_age, unresolved_conversion, unresolved_noc,
unresolved_nomination_expiry, unresolved_sibling, timing_unresolved, unaccepted_test_type, sibling_minor,
arranged_employment_current, arranged_employment_legacy_manual, unaudited_factor, at_risk_component. A
missing reason falls back to the per-finding-kind default. `_action_for(factor_id, reason_code, kind)`
returns `template.format(factor=factor_id)`.

`_quote_map(registry, factor_id) -> dict[str,str]`: build `{citation.chunk_id: citation.quote}` over the
registry rows whose `factor_ids` intersect `auditors.consumed_factor_ids(factor_id)`. Static lookup only.

`_finding_kind(card) -> str | None`: `"gap"` if verdict GAP; `"at_risk"` if AT-RISK; `"unpriced"` if
SUBSTANTIATED and `points_unresolved`; else None (not a finding).

`build_remediation(report, registry) -> PrivateRemediationChecklist`: PURE. For each card, compute
`_finding_kind`; skip None; build the item with citations from `_quote_map` and
`action = _action_for(...)`. For every `rule_citation_id` on a finding card, look up its quote in the
factor's `_quote_map`; if the id has NO quote (registry drift), raise
`RemediationError("registry_drift")` — FAIL CLOSED, never emit an item with a missing/invented quote.
Return the checklist with `source_audit_run_id = report.run_id`,
`candidate_id = report.candidate_id`, and the items IN CARD ORDER. NO timestamp, NO minted id, NO file
I/O — determinism by construction.

`to_public_summary(checklist, private_output_path, *, run_id="") -> PublicRemediationSummary`: down-project
to counts (by finding_kind + verdict) + item_count + the vault-relative path (reject absolute).

`render_remediation_markdown(checklist) -> str`: a vault-only PII-bearing markdown listing each item
(factor, verdict/reason, score impact, citation ids + quote, action) followed by the `SCREENING_NOTICE`.

DO NOT import `searchindex` or `grounding`. DO NOT inline any volatile CRS literal.
