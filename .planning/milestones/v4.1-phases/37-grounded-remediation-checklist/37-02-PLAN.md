- Add `latest_completed_audit_run(vault) -> dict | None`: one parameter-bound
  `SELECT ... FROM audit_runs WHERE status='complete' ORDER BY completed_at DESC, audit_run_id DESC LIMIT 1`
  returning the row dict (or None). (Reuse the load_audit_run column list.)

`crawler/remediation.py` (add to Plan 37-01's module; `RemediationError` is defined in Plan 37-01):
- `_load_report(vault, audit_run_row) -> PrivateAuditReport`: resolve the stored `report_relpath` — which
  `audit_report._vault_relative` anchors at `vault.root.parent.parent` (the personal root), so it is
  `candidates/<id>/output/crs-audit/<run_id>.json` — via
  `paths.resolve_within(vault.root.parent.parent, *audit_run_row["report_relpath"].split("/"))`
  (the exact inverse of `_vault_relative`; do NOT use `resolve_within(vault.root, ...)`, which
  double-counts `candidates/<id>` and yields a spurious unreadable refusal). Read the JSON and
  `PrivateAuditReport.model_validate_json(text)`. Raise `RemediationError("audit_report_unreadable")` on a
  missing file / OSError / ValidationError / PathEscapeError (PII-free — reason token only).
- `run_remediation(vault, audit_run_id=None, *, registry=None) -> tuple[PrivateRemediationChecklist, PublicRemediationSummary]`:
  1. Resolve the target run: if `audit_run_id` is given, `vault.load_audit_run(...)`; require it exists AND
     `status == "complete"` else raise `RemediationError("audit_run_not_found")`. If not given, use
     `vault.latest_completed_audit_run(...)`; if None raise `RemediationError("no_completed_audit")`.
  2. `_load_report(...)`; `registry = registry or crs_rules.load_registry()`.
  3. `checklist = build_remediation(report, registry)` (Plan 37-01 pure fn).
  4. Mint `rem_id = vault.new_remediation_id()`. Write JSON + Markdown ONLY under
     `resolve_within(vault.root, "output", "remediation")` as `<rem_id>.json` / `<rem_id>.md`
     (mkdir parents). The JSON is `checklist.model_dump()`; the Markdown is `render_remediation_markdown`.
  5. `report_relpath = _vault_relative(vault, "output", "remediation", f"{rem_id}.json")`.
  6. `summary = to_public_summary(checklist, report_relpath, run_id=rem_id)`; return `(checklist, summary)`.
  Fail-closed ordering: build FIRST; the writes only happen after a valid checklist exists.
  </action>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| report_relpath -> report load | resolve_within re-anchors the read path; a corrupt/missing report fails closed |
| checklist write -> vault subtree | Every path re-anchored via resolve_within; writes only under output/remediation/ |
| PublicRemediationSummary -> stdout | The PII boundary; counts/ids/vault-relative path only |
