Create `crawler/review_packet.py`:

Models (pydantic v2, `extra="forbid"`, `from __future__ import annotations`):
- `PacketCitation(citation_id: str [pattern relpath#ordinal, reject ev_], quote: str [min_length=1])`.
- `PacketFinding`: `factor_id`, `verdict: Verdict`, `reason_code: str | None`,
  `finding_kind: Literal["gap","at_risk","unpriced"]`, `score_impact: int | None`,
  `substantiated_points: int | None`, `citations: list[PacketCitation]`, `action: str`. NO evidence_ids
  field, NO claimed/confirmed raw value field.
- `IncludedDocument(document_id: str)` (opt-in record — id only, no path/bytes; filled by Plan 38-03).
- `RedactionManifest`: `findings_total: int`, `findings_included: int`, `findings_excluded: int`,
  `redacted_fields: list[str]` (e.g. ["evidence_ids"]), `documents_excluded: int`,
  `documents_included: list[IncludedDocument]`.
- `ReviewPacket`: `source_audit_run_id: str`, `findings: list[PacketFinding]`,
  `manifest: RedactionManifest`, `screening_notice: str`. (No candidate id, no ev_, no bytes.)

Reuse `remediation.SCREENING_NOTICE` (`from crawler.audit_report import SCREENING_NOTICE` — same framing;
never forked).

`build_packet(checklist, selection=None, *, documents_excluded=0, documents_included=None) -> tuple[ReviewPacket, RedactionManifest]`:
PURE. `selection` is a set of factor_ids (None/empty = all). For each checklist item whose factor_id is
selected, project a `PacketFinding` mapping `score_impact = item.score_delta`, `citations =
[PacketCitation(citation_id=c.citation_id, quote=c.quote) for c in item.citations]`, and DROPPING
`item.evidence_ids`. Build the `RedactionManifest` (findings_total = len(checklist.items);
findings_included = len(selected); findings_excluded = total − included; redacted_fields =
["evidence_ids"]; `documents_excluded` and `documents_included` are passed IN by the caller
(`run_review_packet`, which has the vault) — `build_packet` performs NO vault access). Return the
`ReviewPacket` (with `screening_notice=SCREENING_NOTICE`) + the manifest. NO id/timestamp/IO.

`render_packet_markdown(packet) -> str`: a human-readable packet listing each finding (factor, verdict/
reason, score impact, citations id+quote, action) + the screening notice heading. Plain, professional
framing; NO approval/eligibility/outcome-prediction wording.

DO NOT import `searchindex`/`grounding`. DO NOT inline any volatile CRS literal.
