- `PublicPacketSummary` (PII-light, `extra="forbid"`): `run_id: str`, `source_audit_run_id: str`,
  `findings_included: int`, `documents_included: int`, `manifest_counts: dict[str,int]`,
  `private_output_path: str` (vault-relative validator). No ev_/applicant value.
- `run_review_packet(vault, audit_run_id=None, *, selection=None, registry=None) -> tuple[ReviewPacket, PublicPacketSummary]`:
  1. `checklist, run_row = remediation._build_checklist_for_run(vault, audit_run_id, registry=registry)`
     (reuses the report load + fingerprint gate + build; a prerequisite failure raises RemediationError).
  2. `docs = vault.list_candidate_documents(vault, vault.candidate_id)`;
     `packet, manifest = build_packet(checklist, selection, documents_excluded=len(docs))`
     (documents_included = [] here — per-doc opt-in is Plan 38-03).
  3. Mint `pkt_id = vault.new_packet_id()`. Write the packet JSON + Markdown ONLY under
     `resolve_within(vault.root, "output", "review-packet")` as `<pkt_id>.json` / `<pkt_id>.md`.
     (The render-then-scan gate is added in Plan 38-03 BEFORE this write.)
  4. `report_relpath = remediation._vault_relative(vault, "output", "review-packet", f"{pkt_id}.json")`
     (import/reuse the helper).
  5. Return `(packet, PublicPacketSummary(run_id=pkt_id, source_audit_run_id=..., findings_included=...,
     documents_included=0, manifest_counts=..., private_output_path=report_relpath))`.
  Fail-closed ordering: build FIRST; writes only after a valid packet exists. ALL refusals raise
  `remediation.RemediationError` (the class the CLI already catches) — do NOT introduce a new exception type.
