<objective>
Ship the grounded NOC-2021 duty worksheet generator (NOC-01) plus the code-only per-duty
vocabulary (NOC-02 capture). A validated 5-digit claimed NOC resolves its pinned corpus
chunks by EXACT `chunk_id` (no fuzzy/BM25), splits the main-duties chunk into stable,
fingerprinted per-duty items (grouped headers preserved verbatim, never classified), renders
a vault-only cited worksheet with the screening notice, imports it as a `noc_worksheet`
document, and captures one born-pending value per confirmable item (lead statement + each
duty) linked to a dedicated inert `review.noc` factor (NEVER `core.work`, so the frozen
`core.work` audit never sees a duty value).

Purpose: This is the "view a cited worksheet" surface (NOC-01) and the quarantine capture
substrate (NOC-02). It is the interface-first foundation the inert sidecar (Plan 02) and the
CLI (Plan 03) build against — the `noc_duty` value contract (`{duty_id, duty_sha, citation}`)
AND the `factor_id="review.noc"` isolation contract defined here are what downstream plans
consume (the sidecar reads them via `vault.audit_eligible_values(v,"review.noc")`).
Regeneration is idempotent by that same `{duty_id, duty_sha}` contract: an exact rerun reuses
existing values (no duplicate confirm surface, confirmed state preserved), and the sidecar
(Plan 02) counts only the value matching the CURRENT worksheet's `(duty_id, duty_sha)` so a
drifted duty never inflates the count.

Output: `crawler/noc_worksheet.py` (new, pure stdlib), the `noc_duty` / `noc_lead_statement`
FieldName members, and the worksheet-slice unit tests in `crawler/tests/test_noc_review.py`.
</objective>
