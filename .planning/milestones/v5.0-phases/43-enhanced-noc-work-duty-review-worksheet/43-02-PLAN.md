<objective>
Ship the inert `noc_review` duty-review sidecar (NOC-03) plus the two-layer staleness that
makes NOC-02 confirmations trustworthy. The sidecar is an EXACT structural clone of the
shipped `crawler/policy_offer.py`: a pure, read-only roll-up over the born-pending/confirmed
`noc_duty` values from Plan 01 — read via `vault.audit_eligible_values(v,"review.noc")` (the
dedicated inert factor Plan 01 links duty values to, NEVER `core.work`) — that returns a
closed PII-light dict whose `status` is structurally constrained to `{AT-RISK, GAP, N/A}` —
there is no branch that can emit `SUBSTANTIATED` and no score anywhere.

Purpose: NOC-03 caps the duty-review verdict at `AT-RISK` until a human confirms, and NEVER
lets automated matching green it. Confirming individual duties is not the officer's
R87.1(2)(c) essential-duty finding, so even a fully-confirmed, fresh, grounded set terminates
at `AT-RISK (duty_review_manual)`. Two-layer staleness (Layer 1 = shipped 5-key
`is_audit_eligible`; Layer 2 = corpus `chunk_sha` / `quote_is_grounded` drift) demotes any
stale or drifted confirmation to unresolved.

Output: `crawler/noc_review.py` (new, pure stdlib, inert) and the sidecar/staleness/no-scoring
test slice appended to `crawler/tests/test_noc_review.py`.
</objective>
