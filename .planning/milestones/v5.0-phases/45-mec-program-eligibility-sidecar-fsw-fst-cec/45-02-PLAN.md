| Boundary | Description |
|----------|-------------|
| private criterion → public summary | Applicant values and evidence pointers must be dropped structurally |
| manifest/statuses → program outcome | Unknown, missing, N/A, and deterministic failure precedence must be exact |

| sidecar evaluation → filesystem | MEC composition must not create NOC/STUDY side artifacts |
