Express Entry applicant through gathering/validating e-APR documents, where every
requirement statement is grounded in and cited from an authoritative corpus, and

## Cross-phase integration (wired)

Verified by the integration checker against the live pipeline:

`crawl → raw/manifest.json → chunk → corpus/manifest.json → index → corpus.db (FTS5)
→ tools.search (JSON + citations) → ground() → grounding gate → document agents +
checklist + conformance`.

- Manifest hand-offs enforced with hard-fail guards (chunk requires raw manifest;
  index requires corpus manifest).
- All 5 document agents and the checklist route exclusively through the
  search/citation contract (no `sqlite3` access in `tools/doc_agents/*`).
- The grounding gate is genuinely enforcing: a tampered `quoted_span` makes
  `tools.grounding` exit 1 (`quote_not_in_chunk`).
- `CHK-04` exemption logic is a single shared implementation reused by the
  checklist and the proof-of-funds agent.
