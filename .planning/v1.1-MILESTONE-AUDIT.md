## Integration (wired — verified by the integration checker)

- `expand` consumes `coverage.classify_link` as its scope guard and reuses
  `Crawler.crawl_urls`; `--dry-run` shows bounded caps.
- `completeness --remediate` writes crawl4ai-rendered markdown that `chunk.py`'s
  `.md` branch ingests; the remediation→re-chunk flow is connected.
- `refresh` orchestrates crawl→expand→harvest→chunk→index and verifies the
  grounding pipeline (police-cert agent, Layer-1 checklist, conformance) — all green.
- CI runs `coverage` + `completeness --fail-on-gap` + `validate_corpus`.
- All four tools are dual-path reachable (`pr-tools` + `python -m`); the one noted
  gap (`pr-tools completeness` missing `--remediate`) was fixed during the audit.

## End-to-end evidence (exit 0)

- `pytest` → **98 passed**.
- `coverage` reports per-source captured/missing/out-of-scope.
- `completeness --fail-on-gap` → skeleton 0, JS-gap 0 (after remediation).
