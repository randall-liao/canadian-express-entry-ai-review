# Milestone v3.1 — Express Entry Document-Agent Expansion · Audit

**Goal:** Expand the portable document-agent pack from the six v3.0 agents to the full
IRCC Express Entry e-APR document set, adding a grounded, CLI-agnostic review agent for
every remaining mandatory / mandatory-if-applicable document type (plus the cross-cutting
translation requirement), without weakening the grounding-by-construction acceptance bar
or the PII boundary.

**Acceptance bar (inherited, locked):** grounding-by-construction, fail-closed — every
claim an agent emits carries a citation that resolves to a real corpus chunk AND whose
verbatim quote is a normalized substring of that chunk; any uncited/unresolvable/
quote-mismatch claim fails the whole output.

**Verdict: ACHIEVED — `clean`** (the single requirement satisfied, 0 blockers; one
low-severity tech-debt item inherited unchanged from v3.0 by design).

### PII boundary

The new agents keep all personalization in `basis[]` (employer/spouse/child names,
dates, salaries, document images). The grounding gate inspects `claims[]` only and the
renderer writes only grounded, scanned claims to the git-ignored `personal/output/`
boundary, so every new agent is PII-free by construction. The expanded tracked fixture
(`document_agents.jsonl`) self-scans clean and contains no per-country police citation.
