| Boundary | Description |
|----------|-------------|
| User Prompt -> AI Agent CLI | External untrusted question or command entering the AI system |
| AI Agent -> Local Shell (corpus-crawler) | Executing deterministic Python CLI tools via subprocess |
| Public Output Envelope -> External Consumer | Output leaving local system boundary |
